## Codebase Patterns
- AgentFlow 使用 DONE:<AGENT> 标记实现 Agent 间依赖等待
- 所有 Agent 产出统一写入 /tmp/agentflow/ 目录
- sop-flow.jsonl 是 JSONL 格式，每行一个合法 JSON 对象
- agents.json 中的现有 Agent（main, aftersale, sales 等）是通知系统配置，与 SOP 流程 Agent 是两套体系
- launch-agents.sh 使用 tmux 窗口管理各 Agent，通过文件轮询实现依赖等待
- Ralph 为每个 Agent 维护独立目录结构：scripts/ralph/<agent-id>/prd.json + progress.txt
- 各 Agent 的 branchName 格式：ralph/sop-refactor/<agent-dir>（如 ralph/sop-refactor/pm）
